Este es mi perfíl personal de Github. Actualmente, estoy completando la carrera de **Ingeniería en Sistemas de Información** en la _Universidad Tecnológica Nacional - Facultad Regional Delta_ ([Su sitio oficial](https://www.frd.utn.edu.ar/)).

Participé en proyectos de desarrollo, investigación y aplicación de tecnologías, trabajando tanto individualmente como en equipos multidisciplinarios.

## ¿En qué proyectos he trabajado?

Tecnologías más usadas: Python, SQL, React Native

Proyecto de software relacionado con visión artificial y procesamiento de imágenes, sobre **Raspberry Pi 5**. El trabajo se realizó en **Python**, usando módulos de *numpy*, *matplotlib*, *OpenCV*, entre otros.

Aplicaciones web sobre plataformas cloud (**Google Cloud**). Desarrollamos tanto Backend y Frontend implementando **frameworks como Django y React Native**, usando Python y Java Script.

Trabajos de integración de sistemas embebidos, IoT y conectividad, usando **ESP32** y periféricos externos, como sensores, GPS, antenas 4G.
